# JASHUVA GAMES

**Play Forever.**

Premium Progressive Web Application for original forever-playable games.

## Stack

| Layer | Tech |
|-------|------|
| Web | Next.js, React, TypeScript, Tailwind, Framer Motion, PWA, Redux Toolkit, TanStack Query |
| Games | Universal Canvas engine (+ Pixi/Phaser/Three ready), drop-in `/games` folders |
| API | NestJS, GraphQL, Prisma, PostgreSQL, Redis, JWT, Argon2, Stripe |
| Ops | Docker, GitHub Actions, Vercel + Railway + Cloudflare |

## Quick start

```bash
bash scripts/setup.sh
pnpm dev:web   # http://localhost:3000
pnpm dev:api   # http://localhost:4000
```

Or full stack with Docker:

```bash
cp .env.example .env
# set OWNER_PASSWORD, JWT secrets
pnpm docker:up
```

## SUPER OWNER

Created only on first boot from environment variables:

- `OWNER_NAME=Jashuva`
- `OWNER_EMAIL=jashuvawork@gmail.com`
- `OWNER_PASSWORD=` (generated by `scripts/setup.sh` if empty)

Hidden login: `/owner-login` (noindex). Dashboard: `/owner`.

Roles: `SUPER_OWNER` · `ADMIN` · `MODERATOR` · `SUPPORT` · `USER`

## Adding a game

1. Create `/games/<slug>/` (or register in `games/registry.ts`)
2. Export a `create` factory using `@/games/engine/core`
3. Seed metadata via Owner portal or Prisma seed

Scales toward 10,000+ titles via registry discovery.
